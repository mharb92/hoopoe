### DR tooling (chat 11)
The bulk pass is a batch job, not a conversation. Turn limits stop mattering once state lives on disk and in the database.

| Stage | Where | Why |
|---|---|---|
| Freeze the DR prompt, JSON schema and acceptance rules | Chat, Opus | Small, high leverage, no context pressure |
| Batch runner over 2,728 rows into a `dictionary_review` staging table | Claude Code | Resumable by row id, logged, cost-metered; the model doing the linguistic judgement is set by the API call inside the script, so a Sonnet-orchestrated session can call Opus per batch |
| Adjudicate the flagged minority: low confidence, romanization disagreements, ambiguous `level` | Cowork or chat | Judgement work on a worksheet; small volume |
| Native spot check | Human, on a sampled worksheet | |
| Promotion | One SQL step, in-place UPDATE | Staging keeps the originals, so the pass is reversible and the reviewer gets a diff |
