# Hoopoe learning principles
Standing reference · created chat 6 · P19-P23 and the risk rewrite added chat 33 (rework R1) · binding on every spec section from C6 and on the Phase 2 build package.

## Why this exists
B through C4 were approved on sound instincts but without a stated checklist. A retro-audit in chat 6 found seven gaps, four of which should have been caught at C1 and C2. This file makes the check explicit and cheap. Chat 11 added retro check blocks to C1 to C4 (C1.8, C2.9, C3.13, C4.13) recording what that audit found, so the discharge trail is uniform across every section. Chat 33 (rework block R1) adopted P19-P23 from `teaching-foundations.md` and rewrote the risks for lessons the model builds per learner with no native reviewer (D280). Rows marked *pending* are discharged when their rework block lands.

## The set

| # | Principle | What it requires in practice | Discharged by |
|---|---|---|---|
| P1 | Chunking | New items arrive in groups of ~3, not as a list | C4.2 |
| P2 | Cumulative retrieval | Each chunk is retrieved again after the next chunk lands | C4.2 |
| P3 | Exposure count (Nation) | 5+ encounters per word before it is treated as taught; a grammar point is practised across several lessons and weeks before it is. Counted by code at generation, never judged by the model | C4.3; *pending* R4 |
| P4 | Dual coding / multi-modality | Each word and grammar point met in ≥2 of audio, script, production | C4.3; *pending* R4 |
| P5 | Audio-first | Sound precedes script for every new item; audio never autoplays | C2.3, C4.4, C4.8, C9.1, C9.6 |
| P6 | Scaffold fading | Support is withdrawn on evidence, not on preference | C4.8 (`script_stage` ladder) |
| P7 | Mastery learning | Advancement is by demonstrated recall, not coverage | C6 |
| P8 | Spaced repetition | Review intervals expand on success, contract on failure | C6 |
| P9 | Spacing effect | Intervals are measured in calendar days, never in sessions; new material is rate-limited per day | D63, D64 |
| P10 | Comprehensible input (i+1) | Three regimes (D134, amended chat 33). **Graded positions:** only words and grammar points the learner record holds as known (taught, or proved at placement), plus the lesson's own new material, which is the controlled +1. **Generated input prose** (stories, dialogues): may carry untaught material, words capped at a share of tokens (default 10%, D94) and still resolving to real dictionary rows, grammar points tagged so tap-to-explain can explain them. **Learner-directed surfaces:** no gate | C3.5, C5.5 validator, C11.1; *pending* R3-R5 |
| P11 | Functional-notional syllabus | Blocks are framed as can-do outcomes. Can-do goals choose topics and scenarios and the grammar path runs through them, so a grammar point is always taught inside a can-do, never as a standalone chapter | C3.2; *pending* R3 |
| P12 | Interleaving | Review mixes items across units; consecutive units do not repeat a primary category | C6, D70 |
| P13 | Contextual recycling | Earlier vocabulary and structures reappear inside new dialogues and patterns, not only in the review queue | D65; *pending* R3, R4 |
| P14 | Generation effect / desirable difficulty | Production support is withdrawn as mastery rises | D68 |
| P15 | Error-driven remediation | The skill an error is classified to (P23) gets targeted drills, not another pass of the same lesson | D62 |
| P16 | Diagnostic before instruction | Placement sets a ceiling and a script stage, and every output it records drives something | C2, D66, D67 |
| P17 | Intrinsic motivation | Progress is shown as capability; no scores, XP, badges or shaming copy | B7, C1.4, C4.10 |
| P18 | Communicative output | The learner produces language for a purpose, judged as communication | C8.5, C8.6 (text in MVP) |
| P19 | Four strands (Nation) | Each block balances meaning-focused input, meaning-focused output, language-focused study and fluency practice. Checked per block, not per lesson; early blocks lean to study, later ones to input, output and fluency | *pending* R3 (block planner) |
| P20 | Notice, then explain | A grammar point is met first in input with the form highlighted, then explained in English in 3 sentences or fewer, plus a small table | *pending* R4 (grammar lesson) |
| P21 | Automaticity | Grammar moves from declarative to proceduralised to automatic through varied practice. Mastery is measured on the rule, not the word, including verbs never seen conjugated. The automatic stage gets timed practice, timed only on answers that do not depend on typing speed (tap, listen and pick): typing speed is not fluency (C8.5) | *pending* R2 (mastery), R4 (Verb Lab) |
| P22 | Interaction | Regular conversation with a partner at the learner's level, who recasts errors rather than lecturing | *pending* R4 (conversation partner, conversation lesson); at risk R4 |
| P23 | Diagnostic feedback | Every error is classified (wrong ending, wrong stem, agreement, wrong word, spelling) and named to the learner; P15 acts on the class | *pending* R2 (learner record), R4 (quizzes) |

## The gate
Every section proposal from C6 onward, and the Phase 2 build package, ends with a principles check:

```
### Cn.x Principles check
Discharges: P_, P_ (one line each on how)
Defers: P_ → §__
At risk: P_ (why, and the mitigation or the recorded risk id)
```

A section that discharges nothing and defers everything is not finished. A section that puts a principle at risk without naming a mitigation or filing a risk row does not get approved.
